# 재구축 기획안 (사용자와 함께 확정해 가는 문서)

목적: 하남 미사 가족(4인/파킨슨 아버님 동행 6인)이 **실제로 믿고 갈 수 있는** 나들이·캠핑·동네 맛집/카페 추천을,
스마트폰에서 바로 열고 **네이버 내비를 즉시 켤 수 있게** 제공한다. 근거는 실제 유튜브 영상·네이버 후기·네이버 플레이스 수치.

## 파이프라인
```
발굴(유튜브·네이버 검색) → 읽기(자막·후기 본문을 AI가 판독) → 장소 확정(네이버 플레이스 ID/좌표/별점)
   → 게이트(폐업·별점·리뷰수·거리·예산·모드B) → 점수화(docs/SCORING.md) → 코스 조합
   → 웹 게시(GitHub Pages) → 카톡 알림
```
- **읽기**가 핵심: 요약 수치(조회수)만 보지 않고 자막에서 가격·주차·경사·좌석형태·아이 반응을 직접 뽑아 근거 문구+타임스탬프로 저장
- **장소 확정**은 사람 손이 아니라 네이버 플레이스 값으로만(좌표·주소·ID). 자막의 고유명사 오인식은 여기서 걸러짐

## 화면(스마트폰 우선)
1. **나들이 코스** — 지역/테마 필터, 4인·6인 토글, 카드마다 총점·별점·운전시간·근거 링크(타임스탬프)·확인 필요 항목·**[네이버 내비 시작]**
2. **키즈캠핑** — 같은 구조
3. **우리 동네(도보·차량 10분)** — 카테고리별 맛집/카페
4. **이번 주말 추천** — 날씨·계절·최신성 기반 상위 3개(카톡으로도 발송)

## 갱신 방식 (정직하게)
| 작업 | 방법 | 자동화 |
|---|---|---|
| 별점·리뷰수·영업상태 재확인, 링크 점검 | 네이버 플레이스 저속 재조회 | 가능(주기 실행) |
| 새 장소 발굴 + 영상/후기 읽기 | 유튜브·네이버 수집 + Claude가 읽고 판단 | **Claude 세션에서 수행**("이번 달 갱신해줘") — 완전 무인은 유튜브 봇 차단·판독 품질 때문에 지금은 권하지 않음 |
| 웹 반영·카톡 알림 | GitHub 푸시 → Pages, 카카오 나에게 보내기 | 가능 |

## 로드맵
- [x] 세션 복원, 1차본 감사·정리, 도구 설치, 추천 기준·데이터 구조 설계
- [ ] 기획 확정(이 문서의 "결정 필요" 항목)
- [ ] 유튜브 차단 해제 후 저속 자막 수집 → 장소 추출
- [ ] 첫 배치(파일럿 10~15곳) 끝까지 검증 → 사용자 검토
- [ ] 새 웹 + verify 도구 + 네이버 내비 링크 실기기 테스트(사용자 폰)
- [ ] 확대(20선/캠핑 20선/동네) → 푸시 → 카톡 개편

## 결정 필요 (사용자와)

2. 첫 배치 우선순위
3. 갱신 방식
4. 평소 신뢰하는 유튜브 채널/블로거가 있는지 (우선 가중치)
