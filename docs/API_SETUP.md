# API 준비 가이드

원칙: **공식 API가 있으면 공식 API.** 스크래핑은 IP 차단(2026-09-24 사고)과 정책 위험이 있어 보조수단으로만 씁니다.
키는 `.env`(이 PC, gitignore)와 GitHub Secrets(클라우드 자동화용)에만 보관하고 채팅·로그·커밋에 값을 남기지 않습니다.

## 우선순위

| # | API | 무엇에 쓰나 | 비용 | 사용자가 하실 일 | 제가 할 일 |
|---|---|---|---|---|---|
| 1 | **YouTube Data API v3** | 영상 검색, 조회수·좋아요·**댓글 수**·채널 **구독자 수**, 댓글 읽기(“폐업했어요/가격 올랐어요” 탐지). 스크래핑 차단 문제 해결 | 무료(일 10,000유닛. 검색 1회=100, 상세 50개=1) | 구글 로그인, 약관 동의·캡차 | 프로젝트 생성 → API 사용 설정 → 키 발급 → 키 제한(YouTube Data API v3만) → `.env` 저장 |
| 2 | **네이버 오픈API (검색)** | 블로그·카페 **최신 후기**(제목·링크·날짜·요약), 지역검색(이름·주소·좌표) | 무료(일 25,000회) | 네이버 로그인(본인인증 요구 시) | 애플리케이션 등록(사용 API: 검색) → Client ID/Secret → `.env` 저장 |
| 3 | **카카오 로컬** | 장소 검색·좌표·카카오 장소ID, **카카오맵 별점** 교차확인(네이버에 별점 없는 관광지 보완) | 무료 | 카카오 로그인 | 기존 앱 `가족나들이` → 제품 설정 → 카카오맵 **사용 설정 ON** |
| 4 | **Google Places API (New)** (사용자 선택: 진행) | **구글 별점·리뷰 수**(네이버 별점이 없는 곳 보완), **폐업 여부**(`businessStatus`), 주차 옵션, 입구 단차 여부(휠체어는 안 타시므로 "계단 없는 입구"의 약한 신호로만 참고) | 결제수단 등록 필요, 우리 사용량은 무료 한도 안(상한 설정 가능) | **카드 정보 직접 입력**, 예산 알림 설정 | 키 발급·제한, 호출량 상한 설정 |
| 5 | (선택) 공공데이터포털 기상청 단기예보 | “이번 주말 추천”에 날씨 반영 | 무료 | 공공데이터포털 로그인 | 활용신청·키 저장 |
| 6 | (선택) GitHub 로그인(gh) + Secrets | 클라우드에서 별점 갱신·카톡 알림 자동 실행 | 무료 | 기기 코드 승인 1회 | 워크플로·Secrets 설정 |

## 진행 방식 (제안)
1. 브라우저 패널(앱 내장 브라우저)에서 **직접 로그인**해 주세요. 비밀번호는 제가 입력하지 않습니다.
2. 로그인된 화면에서 제가 클릭·입력을 대신해 키를 발급하고 `.env`에 저장합니다. 캡차/결제/본인인증이 뜨면 그 단계만 부탁드립니다.
3. 발급 직후 각 키를 1회 호출해 정상 동작만 확인합니다(값은 마스킹 표시).

## 왜 이 순서인가
- 1·2번이 있으면 “최신 영상+최신 후기”를 **차단 없이 공식적으로** 모을 수 있음.
- 3번은 1분이면 끝나고, 네이버가 별점을 안 주는 관광지(쁘띠프랑스·송도 센트럴파크 등)를 보완.
- 4번은 폐업 여부 이중 확인과 별점 보완용. 결제수단 등록이 필요하지만 사용자가 진행하기로 함(호출량 상한·예산 알림을 반드시 설정).

## 남는 한계
- 유튜브 **자막 원문**은 공식 API로 받을 수 없음(타인 영상). 차단 해제 후 저속(요청 간 ≥20초)으로 받거나, 영상 설명·챕터·댓글로 보완.
