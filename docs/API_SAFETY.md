# API 안전캡 — "돈이 나가지 않게"

원칙 세 가지 (사용자 지시, 2026-09-24): ① 구글 API는 **월 무료 사용 한도 안에서만**, ② **코드에서 하루 호출 횟수를 하드캡**, ③ 유료 가능 API는 **무료 체험판 상태에서만** 켠다. 결제 연결은 해제하지 않고 유지.

## 겹겹이 있는 안전장치
| 층 | 내용 | 강도 |
|---|---|---|
| 1. 구글이 고정한 무료 한도 | YouTube Data API v3: 하루 10,000 유닛, 검색은 하루 100회. 콘솔에서 **조정 불가**. **유료 구간이 없어서** 넘으면 요금이 아니라 오류(403)만 난다 | 구조적(과금 불가) |
| 2. 우리 코드 하드캡 | `config/limits.json` 의 `caps`. 하루 3,000 유닛 / 검색 40회(구글 한도의 30~40%), 월 60,000 유닛 / 800회. 호출 직전에 차감, 초과 시 예외로 즉시 중단 | 코드 강제 |
| 3. 구글 API 화이트리스트 | `google.allowed_apis = ["youtube"]` 밖의 구글 API는 호출 자체를 거부(Places·Maps·Gemini 등) | 코드 강제 |
| 4. 유료 가능 API 이중 잠금 | `paid_apis_enabled` 에 **사용자 승인으로 명시**되고 **오늘 ≤ 체험판 종료일(2026-11-26)** 일 때만 허용. 종료일이 지나면 승인했어도 거부 | 코드 강제 |
| 5. 프로젝트 상태 | `family-trip` 에 켜진 API 는 YouTube Data API v3 + 구글 기본 무료 서비스뿐. 결제 계정은 **무료 체험판**(업그레이드 전에는 청구 없음) | 계정 상태 |
| 6. 스크래핑 캡 | 유튜브 스크래핑(`youtube_scrape`)은 **0(금지)**. 2026-09-24 집 IP 구글 차단 사고 이후. 네이버 플레이스는 하루 400 | 코드 강제 |
| 7. 킬스위치 | 환경변수 `TRIP_API_KILL=1` 이면 모든 외부 호출 거부 | 수동 |

## 시험 결과
`python tools/test_quota_guard.py` — 17개 전부 통과: 일/월 한도 차단, 초과 시도가 장부에 안 올라감, 스크래핑 0캡, 유료 API 금지, 체험판 종료일 로직, 킬스위치.
실제 호출(`tools/yt_api_check.py`)이 장부에 1 유닛으로 기록되는 것도 확인.

## 정직한 한계
- 구글의 **예산 알림은 이메일만 보내고 지출을 막지 않는다.** 그래서 알림에 기대지 않고 위 캡들로 막는다.
- 장부는 이 PC의 `data/cache/api_usage.json`. **GitHub Actions에서는 실행마다 초기화**되므로 클라우드 실행은 "1회 실행 = 하루 한도"로 설계하고 주 1회 정도만 돌린다.
- 이 캡은 **이 프로젝트의 코드**에만 적용된다. 같은 결제 계정의 다른 프로젝트(`dwp-audit-ai` 등)는 별개이며 건드리지 않았다.
- 체험판이 끝난 뒤(2026-11-26~)에는 유료 업그레이드 여부가 사용자 결정이며, 업그레이드 전에는 청구되지 않는다(화면 안내 기준).

## 한도를 올리거나 유료 API를 쓰려면
1. 사용자가 명시적으로 승인한다.
2. 무료 체험판 기간인지 확인한다(만료 후에는 코드가 거부).
3. `config/limits.json` 을 수정하고 `tools/test_quota_guard.py` 를 다시 통과시킨다.
