# 추천 기준 (Scoring & Gates)

"믿을 수 있는 최신 자료 + 우리 가족에 맞는 곳"만 올리기 위한 기준. 숫자는 `config/criteria.json`에서 조정.

원칙: **① 걸러내기(게이트) → ② 점수 → ③ 근거 표시.** 근거가 없는 칸은 채우지 않고 "확인 필요"로 남긴다.

## 1. 게이트 (하나라도 걸리면 추천 목록에서 제외)
| 게이트 | 기본값 | 이유 |
|---|---|---|
| 폐업/휴업/이전 | 네이버 영업상태 + 최근 영상 댓글·블로그의 폐업 언급 | 가장 치명적인 오류. 가서 헛걸음 |
| 네이버 방문자 별점 | 관광·캠핑 4.2↑ / 식당·카페 4.3↑ | 아래 "왜 4.5가 아닌가" 참고 |
| 리뷰 수 | 관광·식당·카페 **300↑** / 캠핑 **50↑** (네이버 방문자 + 카카오 리뷰 합, 2026-09-24 사용자 조정) | 리뷰 3개짜리 5.0을 걸러냄 |
| 편도 운전 | 90분 이내 (선호 60분) | OSRM 계산값. 주말 정체는 +20~30% 안내 |
| 4인 한 끼 | 10만원 이하 (근거 있는 가격만 판정) | 가족 예산 기준 |
| 출처 | 실제 영상/블로그 1개 이상 | 근거 없는 항목 금지 |
| 모드 B 배제 | 필수 동선에 계단·급경사, 좌식 전용 | 파킨슨 환우 안전. 근거 있을 때만 배제, 없으면 "확인 필요" |

**왜 별점 4.5 고정이 아닌가:** 네이버 방문자 별점은 대체로 4.2~4.6에 몰려 있다(예: 화담숲 4.49, 리뷰 1.1만).
4.5를 하드컷으로 두면 화담숲 같은 대표 명소도 탈락한다. 그래서 **4.5 이상은 "고평점" 배지 + 가점**, 하한선은 4.2~4.3으로 두고 리뷰 수로 신뢰도를 보정한다.

## 2. 추천 점수 (0~100)
| 항목 | 만점 | 산정 |
|---|---|---|
| 장소 평판 | 35 | 베이지안 보정 별점(prior 4.2, 가중 100리뷰)으로 최대 25 + 리뷰 규모(방문자+블로그, log) 최대 10 |
| 콘텐츠 근거 | 25 | 독립 출처 수(채널·블로그 중복 제외) 1개 8 / 2개 15 / 3개+ 20 + 최고 출처 신뢰도 보너스 5 |
| 가족 적합도 | 25 | 모드A(아이 체험 근거) 12 + 모드B(무장애·입식·주차 근거) 13. **자막/블로그 본문에서 근거 문구가 나온 만큼만** 가점 |
| 실용성 | 15 | 운전 ≤30분 8 / ≤60분 6 / ≤90분 2 + 4인 식비 ≤7만 7 / ≤10만 5 / 근거없음 2 |

등급: **추천 ≥70 · 조건부 55~69 · 근거부족**(게이트는 통과했으나 리뷰/근거가 적음 → 후보로만 표시).

## 3. 출처(영상) 신뢰도 S (0~100)
| 항목 | 만점 | 산정 |
|---|---|---|
| 최신성 | 25 | 6개월 이내 25 / 12개월 20 / 24개월 12 / 36개월 6 / 그 이상 0 |
| 반응 | 25 | 조회수(log), 댓글 수, 좋아요율. 조회수 대비 참여율로 소형 채널도 공정하게 |
| 채널 신뢰 | 20 | 구독자(log) + 여행 콘텐츠 지속성 |
| 정보 밀도 | 20 | 한국어 자막 유무, 길이 5~40분, 챕터, 자막 내 가격·주차·시설 언급 수 |
| 광고 편향 | -10~0 | 제목·설명에 협찬/유료광고/체험단/제공받아 등 → 감점(표기 자체는 투명하므로 가중은 작게) |

## 4. 최신성 관리
- 모든 항목에 `evidence_date`(가장 최근 근거 날짜)와 `verified_at`(별점·영업상태 확인일)을 남긴다.
- 근거가 24개월보다 오래되면 "정보 오래됨 — 가격·영업 재확인" 배지.
- 별점·영업상태는 주기적으로 재수집해 갱신, 하한선 아래로 내려가면 자동 강등.

## 5. 화면에 보이는 것 (사용자가 판단하는 방식)
카드마다: 총점·등급 / 네이버 별점·리뷰 수 / 운전시간 / 근거 영상(타임스탬프 링크)·블로그 / 가격 근거 /
모드B 근거 문구(예: `영상 03:12 "입구부터 평지"`) / **확인 필요 항목** / 네이버 내비 시작 버튼.

## 6. 한계 (숨기지 않는다)
- 네이버 별점은 공개 플레이스 페이지에서 읽어오는 값이라 네이버 정책 변경 시 수집 방식이 깨질 수 있다.
- 유튜브 자막은 자동 생성이라 고유명사 오인식이 있다 → 장소는 반드시 지도 검색으로 재확인 후 등록.
- 무장애 여부는 "영상·후기에 그렇다고 나온 근거"일 뿐 현장 보증이 아니다. 아버님 동행 전에는 시설에 직접 문의 권장.
